# 🎯 승진 심사 모의 면접

## Promotion Interview Simulator

회계법인 **파트너 패널 승진 인터뷰**를 텍스트 또는 음성으로 연습할 수 있는 **AI 기반 싱글 HTML 웹앱**입니다.

별도의 프레임워크나 빌드 과정 없이 **순수 HTML / CSS / JavaScript**로 작성되어 있으며, `index.html` 파일을 브라우저에서 직접 실행하거나 **GitHub Pages** 등 정적 웹 호스팅 환경에 배포할 수 있습니다.

---

## ✨ 주요 기능

### 📋 01. 자료 준비

실제 승진 심사 환경에 맞춰 면접 조건과 AI가 참고할 자료를 입력할 수 있습니다.

* **승진 대상 직급** 설정
* **면접 스타일** 선택

  * 압박형
  * 균형형
  * 코칭형
* **패널 구성** 선택

  * 1인 패널
  * 3인 패널
* **참고 자료 입력**

  * 자기소개서
  * 주요 프로젝트 및 실적
  * 매출 및 Business Development 실적
  * 인사평가 / 승진 평가 기준
  * 조직 기여 및 리더십 자료
  * 기타 면접 참고 자료
* 텍스트 직접 입력 / 붙여넣기
* `.txt` / `.md` 파일 업로드 지원

---

### 📚 02. 예시 학습

실제 모의 면접을 시작하기 전에 입력한 자료를 기반으로 **예상 질문과 모범 답안을 먼저 학습**할 수 있습니다.

AI가 참고 자료를 분석해 다음 내용을 생성합니다.

* 예상 질문 **6개**
* 각 질문별 **모범 답안 예시**
* 입력한 경력·실적·평가 기준을 반영한 맞춤형 답변
* 문항별 답변 음성 재생
* 전체 질문·답변 연속 음성 재생

직접 답변하지 않고 먼저 예상 질문과 답변 구조를 익힐 수 있기 때문에 **승진 인터뷰 사전 학습용**으로 활용할 수 있습니다.

```text
참고 자료 입력
      ↓
AI 자료 분석
      ↓
예상 질문 6개 생성
      ↓
모범 답안 확인
      ↓
텍스트 / 음성으로 학습
      ↓
실제 모의 면접 진행
```

---

### 🎙️ 03. 모의 면접

입력한 자료를 기반으로 AI 면접관과 실제 인터뷰와 유사한 형태의 대화를 진행할 수 있습니다.

#### 지원 기능

* 💬 **텍스트 채팅**
* 🎙️ **브라우저 음성 인식**
* 🔊 **AI 질문 음성 출력(TTS)**
* 입력 자료 기반 맞춤형 질문
* 답변 내용에 따른 추가 질문
* 선택한 면접 스타일에 따른 질문 강도 조정
* 1인 / 3인 패널 면접 방식 지원

면접관은 단순히 사전에 준비된 질문만 순차적으로 제시하는 것이 아니라, 사용자의 답변 내용을 참고해 후속 질문을 이어갈 수 있도록 구성할 수 있습니다.

---

### 📊 04. 인터뷰 피드백

모의 면접 종료 후 전체 질문과 답변을 기반으로 구조화된 피드백을 제공합니다.

#### 제공되는 평가

* ✅ **잘한 점**
* ⚠️ **보완할 점**
* 📊 **종합 평가**
* 💡 **실전 인터뷰 Tip**

또한 실제 면접 과정에서 중요도가 높았던 질문 중 **3개를 선정**해 입력한 참고 자료를 반영한 **모범 답안 예시**를 추가로 제공합니다.

```text
모의 면접 종료
      ↓
전체 답변 분석
      ↓
잘한 점 / 보완할 점
      ↓
종합 평가
      ↓
중요 질문 3개 선정
      ↓
질문별 모범 답안 제공
      ↓
실전 인터뷰 Tip
```

전체 면접 기록은 복사할 수 있어 별도로 저장하거나 이후 답변 개선에 활용할 수 있습니다.


```text

```

# 🤖 AI 모델

이 앱은 **Anthropic API**를 이용해 Claude 모델을 호출합니다.

기본 모델은 **Claude Haiku 4.5**입니다.

```javascript
const ANTHROPIC_MODEL = "claude-haiku-4-5-20251001";
```

Claude Haiku 4.5를 기본 모델로 사용하는 목적은 모의 면접에 필요한 다음 요소 간 균형을 고려하기 위함입니다.

* 한국어 질의·응답
* 빠른 응답 속도
* 반복적인 인터뷰 진행
* 문맥을 고려한 후속 질문
* 구조화된 피드백
* API 사용 비용

## 🧠 고급 모델 사용

보다 정교한 질문이나 심층적인 피드백이 필요한 경우 **Claude Sonnet 5**를 사용할 수 있습니다.

`callModelOnce` 함수에서 다음 값을 변경합니다.

### 기본 설정

```javascript
const ANTHROPIC_MODEL = "claude-haiku-4-5-20251001";
```

### Sonnet 5 사용

```javascript
const ANTHROPIC_MODEL = "claude-sonnet-5";
```

### 권장 활용

| 모델                   | 권장 용도             |
| -------------------- | ----------------- |
| **Claude Haiku 4.5** | 반복적인 일반 모의 면접     |
| **Claude Sonnet 5**  | 최종 실전 점검 / 심층 면접  |
| **Claude Sonnet 5**  | 보다 정교한 답변 평가 및 개선 |

예를 들어 평소에는 Haiku 4.5로 반복 연습하고, 실제 면접 직전에는 Sonnet 5를 이용해 보다 정교한 질문과 피드백을 받는 방식으로 활용할 수 있습니다.

# 🔑 Anthropic API Key

> [!IMPORTANT]
> AI 모의 면접 기능을 사용하려면 **Anthropic API Key가 필요합니다.**

화면의 다음 위치에 API Key를 입력합니다.

```text
01 자료 준비
    └─ F. Anthropic API Key
```

Anthropic Console에서 API Key를 생성할 수 있습니다.

```text
Anthropic Console
    └─ Settings
        └─ API Keys
```

API 이용은 Claude.ai의 일반 Free / Pro / Max 구독과 별도로 관리됩니다.

Anthropic Console에서 API 사용을 위한 **Usage Credit**을 충전한 후 실제 사용량에 따라 차감됩니다.

> [!NOTE]
> 실제 비용은 사용하는 모델, 입력한 자료의 양, 대화 길이 및 출력 토큰 수에 따라 달라질 수 있습니다.
>
> 최신 가격은 Anthropic의 공식 API Pricing 정보를 확인하는 것을 권장합니다.

`이 브라우저에 저장` 옵션을 활성화한 경우 API Key를 브라우저의 `localStorage`에 저장하도록 구성할 수 있습니다.

```javascript
localStorage
```

> [!WARNING]
> **공용 PC에서는 API Key 저장 기능을 사용하지 않는 것을 권장합니다.**

특히 다음 환경에서는 저장하지 마세요.

* PC방
* 공용 PC
* 공유 업무용 PC
* 여러 사용자가 동일한 Browser Profile을 사용하는 환경

# 🚨 GitHub 업로드 시 API Key 주의

> [!CAUTION]
> **Anthropic API Key를 GitHub Repository에 절대로 포함하지 마세요.**

다음과 같이 API Key를 HTML 또는 JavaScript 코드에 직접 입력해서는 안 됩니다.

```javascript
// ❌ 잘못된 예
const API_KEY = "sk-ant-api03-xxxxxxxxxxxxxxxx";
```

GitHub에 Commit 또는 Push하기 전에 반드시 다음 사항을 확인하세요.

* [ ] `index.html`에 API Key가 포함되어 있지 않은지 확인
* [ ] JavaScript 코드에 API Key가 Hard Coding되어 있지 않은지 확인
* [ ] 테스트 과정에서 입력한 Key가 남아 있지 않은지 확인
* [ ] `.env` 등 설정 파일이 Commit되지 않았는지 확인
* [ ] Git Commit History에 API Key가 존재하지 않는지 확인

> [!IMPORTANT]
> API Key가 GitHub에 노출되었다면 코드에서 삭제하는 것만으로는 충분하지 않습니다.
>
> **노출된 API Key를 즉시 폐기(Revoke)하고 새로운 Key를 발급하세요.**

# 🛡️ 개인정보 및 회사 내부정보

승진 인터뷰 자료에는 다음과 같은 민감한 정보가 포함될 수 있습니다.

* 자기소개서
* 인사평가
* 고객사 정보
* 프로젝트 정보

* 사업전략
* 미공개 실적

Anthropic API와 같은 상업용 제품은 기본적으로 사용자의 입력·출력을 모델 학습에 이용하지 않는 정책을 적용하고 있지만, 회사 또는 고객사의 내부정보를 입력할 때는 별도의 보안 검토가 필요할 수 있습니다.

가능하면 민감한 정보는 **비식별화 또는 일반화**한 후 입력하는 것을 권장합니다.

### 예시

```text
KB○○카드
→ 국내 대형 카드사

○○전자
→ 국내 대형 제조기업

12억 원 규모 계약
→ 대규모 보안 컨설팅 계약

홍길동 부장
→ 고객사 담당자
```

### 입력하지 않는 것을 권장하는 정보

* ID / Password
* API Key / Access Token
* 주민등록번호
* 금융정보
* 고객 개인정보
* 미공개 소스코드
* 시스템 관리자 계정
* 중요 시스템 IP
* 상세 보안 아키텍처
* 회사 기밀정보

# ⚠️ 브라우저 직접 API 호출

현재 앱은 별도의 Backend 없이 브라우저에서 Anthropic API를 호출하는 단순한 구조로 사용할 수 있습니다.

```text
┌──────────────────────────┐
│      사용자 Browser       │
│                          │
│  index.html              │
│  JavaScript              │
│  사용자 API Key          │
└────────────┬─────────────┘
             │
             │ HTTPS
             ▼
┌──────────────────────────┐
│      Anthropic API       │
└────────────┬─────────────┘
             │
             ▼
┌──────────────────────────┐
│        Claude AI         │
└──────────────────────────┘
```

이 구조는 별도의 서버 구축이 필요하지 않아 **개인이 직접 사용하는 연습 도구**로는 간단하게 사용할 수 있습니다.

하지만 API Key가 브라우저 환경에 존재하기 때문에 **불특정 다수가 사용하는 공개 서비스 구조에는 권장하지 않습니다.**

# 🏢 여러 사람이 사용하는 경우

회사 내부 또는 여러 사용자가 함께 사용하는 서비스로 제공하려면 **Backend 또는 Serverless Proxy**를 추가하는 것이 좋습니다.

### 권장 구조

```text
┌──────────────────────────┐
│       사용자 Browser      │
└────────────┬─────────────┘
             │
             ▼
┌──────────────────────────┐
│ GitHub Pages / Web App   │
└────────────┬─────────────┘
             │
             ▼
┌──────────────────────────┐
│ Backend / Serverless     │
│ Proxy                    │
│                          │
│ • Anthropic API Key 보호 │
│ • 사용자 인증            │
│ • Rate Limiting          │
│ • 입력 데이터 검증       │
│ • 비용 / 사용량 통제     │
└────────────┬─────────────┘
             │
             ▼
┌──────────────────────────┐
│      Anthropic API       │
└────────────┬─────────────┘
             │
             ▼
        Claude AI
```

사용 가능한 예시는 다음과 같습니다.

* Cloudflare Workers
* AWS Lambda / API Gateway
* Azure Functions
* Google Cloud Functions
* Vercel Functions
* Netlify Functions

Proxy 구조로 변경할 경우 기존 인터뷰 UI와 로직은 유지하면서 `callModelOnce` 함수의 API 요청 부분을 Proxy Endpoint에 맞게 변경할 수 있습니다.

```javascript
fetch(...)
```

주요 변경 대상은 다음과 같습니다.

```text
API Endpoint
API 인증 방식
Request Header
Response 처리
```

## 🔊 음성 합성 (TTS)

면접관 질문과 예시 답변을 음성으로 들려주는 기능은 브라우저의 음성 합성 기능을 사용합니다.

```javascript
window.speechSynthesis
```

다음과 같은 용도로 사용할 수 있습니다.

* AI 면접관 질문 읽기
* 예시 학습 모범 답안 읽기
* 문항별 음성 재생
* 전체 질문·답변 연속 재생

운영체제 또는 브라우저에 한국어 음성이 설치되어 있지 않은 경우 기본 음성으로 대체될 수 있습니다.

# 💡 추천 학습 방법

모의 면접 기능을 다음 순서로 활용하는 것을 권장합니다.

```text
① 자기소개서 / 실적 / 평가기준 입력
                  ↓
② 예시 학습
                  ↓
③ 예상 질문 6개 + 모범 답안 확인
                  ↓
④ 균형형 모의 면접
                  ↓
⑤ AI 피드백 확인
                  ↓
⑥ 부족한 답변 수정
                  ↓
⑦ 압박형 모의 면접
                  ↓
⑧ 중요 질문 3개 모범 답안 확인
                  ↓
⑨ 필요 시 Sonnet 5로 최종 점검
                  ↓
⑩ 실제 인터뷰 준비
```

> **모범 답안을 그대로 암기하기보다는 답변의 구조와 핵심 메시지를 익힌 뒤 자신의 표현으로 반복 연습하는 방식이 효과적입니다.**
