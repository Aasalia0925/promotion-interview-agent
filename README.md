#승진 심사 모의 면접 (Promotion Interview Simulator)
회계법인 파트너 패널 승진 인터뷰를 텍스트 또는 음성으로 연습할 수 있는 싱글 HTML 웹앱입니다.
프레임워크 의존성 없이 순수 HTML/CSS/JS로 작성되어 있어 정적 파일 그대로 브라우저에서 열거나
GitHub Pages 등 어떤 정적 호스팅에도 바로 배포할 수 있습니다.
주요 기능
자료 준비: 승진 대상 직급, 면접 스타일(압박형/균형형/코칭형), 패널 구성(1인/3인),
자기소개서·실적·평가 기준 등 참고 자료 입력 (텍스트 붙여넣기 또는 `.txt`/`.md` 파일 업로드)
모의 면접: 텍스트 채팅 또는 브라우저 음성 인식(Web Speech API)으로 실시간 대화 진행,
AI 질문을 음성(TTS)으로 듣기 지원
피드백: 면접 종료 후 잘한 점 / 보완할 점 / 종합 평가 / 실전 팁을 구조화된 형태로 제공,
전체 기록 복사 가능
실행 방법
`index.html` 파일을 브라우저에서 열면 바로 사용할 수 있습니다.
```bash
# 로컬에서 간단히 띄우고 싶다면
python3 -m http.server 8000
# 이후 브라우저에서 http://localhost:8000 접속
```
중요: API 연결에 대해
이 앱은 OpenRouter를 통해 Google: Gemma 4 31B (free) 모델을 호출합니다. 별도 서버나 백엔드 없이,
브라우저에서 OpenRouter API를 직접 호출하는 구조입니다.
사용하려면 OpenRouter API 키가 반드시 필요합니다. (Claude.ai 미리보기 안에서든, GitHub Pages에
배포한 뒤든 예외 없이 필요합니다.) "01 자료 준비" 탭의 F번 항목에 키를 붙여넣으면 바로 동작합니다.
키는 https://openrouter.ai → Keys 메뉴에서 신용카드 없이 무료로 발급받을 수 있습니다.
무료(`:free`) 모델은 분당 20회, 하루 50회 요청 제한이 있습니다. (OpenRouter 계정에 한 번이라도
10달러 이상 충전한 적이 있으면 하루 1,000회로 늘어납니다.) 혼자 연습용으로는 하루 50회로도 충분합니다.
키는 이 브라우저에서 OpenRouter API로만 직접 전송되며, 그 외 어디로도 전송되지 않습니다.
"이 브라우저에 저장"을 켜면 `localStorage`에 저장되어 다음에 다시 입력하지 않아도 되지만,
공용 PC에서는 사용을 권장하지 않습니다.
이 파일을 다른 사람과 공유하거나 GitHub 같은 공개 저장소에 올릴 때는 키를 반드시 지우고 올려주세요.
파일 자체에는 키가 저장되지 않지만(브라우저 저장소에만 남음), 혹시 실수로 값을 채운 채 커밋하지 않도록 주의하세요.
데이터 정책 주의: 무료 모델은 제공사의 정책에 따라 입력 내용이 모델 개선 등에 활용될 수 있습니다.
자기소개서·실적 등 민감한 개인정보는 꼭 필요한 만큼만 입력하시길 권장합니다. 최신 정책은
https://openrouter.ai/google/gemma-4-31b-it:free 페이지에서 확인할 수 있습니다.
더 안전하게 여러 사람이 함께 쓰는 형태로 배포하려면, 키를 서버 쪽에 두는 자체 백엔드/서버리스 프록시를
추가하는 것을 권장합니다. 이 경우 `callClaude` 함수의 `fetch` 대상 URL과 헤더 부분만 그 프록시에 맞게
교체하면 나머지 로직은 그대로 재사용할 수 있습니다.
다른 모델로 바꾸고 싶다면 `callClaude` 함수 안의 `OPENROUTER_MODEL` 값을 원하는 모델의
OpenRouter 모델 ID(예: `google/gemma-4-31b-it:free`)로 바꾸면 됩니다.
브라우저 호환성
음성 인식(마이크 입력)은 Web Speech API를 사용하며 Chrome/Edge 계열에서 가장 안정적으로 동작합니다.
지원하지 않는 브라우저에서는 자동으로 텍스트 입력만 활성화됩니다.
음성 합성(TTS)은 대부분의 최신 브라우저에서 동작하며, 설치된 한국어 음성이 없을 경우
기본 음성으로 대체됩니다.
