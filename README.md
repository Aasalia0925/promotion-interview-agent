# 승진 심사 모의 면접

## Promotion Interview Simulator

회계법인 **파트너 패널 승진 인터뷰**를 텍스트 또는 음성으로 연습할 수 있는 **AI 기반 싱글 HTML 웹앱**입니다.

별도의 프레임워크나 빌드 과정 없이 **순수 HTML / CSS / JavaScript**로 작성되어 있으며, `index.html` 파일을 브라우저에서 직접 실행하거나 **GitHub Pages** 등 정적 웹 호스팅 환경에 배포할 수 있습니다.

---

## 주요 기능

### 01. 자료 준비

실제 승진 심사 환경에 맞게 면접 조건과 AI가 참고할 자료를 입력할 수 있습니다.

* **승진 대상 직급** 설정
* **면접 스타일** 선택

  * 압박형
  * 균형형
  * 코칭형
* **패널 구성** 선택

  * 1인 패널
  * 3인 패널
* **참고 자료 입력**

  * 자기소개서
  * 주요 프로젝트 및 실적
  * 매출 및 Business Development 실적
  * 인사평가 / 승진 평가 기준
  * 조직 기여 및 리더십 자료
  * 기타 인터뷰 참고자료
* 텍스트 직접 입력 / 붙여넣기
* `.txt` / `.md` 파일 업로드
* **과거 실제 인터뷰 기출 질문 입력**

  * 선택 입력
  * 최대 10개
  * 실제 승진 인터뷰에서 받았던 질문을 학습 및 면접에 활용

### 02. 예시 학습

실제 모의 면접을 진행하기 전에 **기출 질문과 예상 질문에 대한 모범 답안을 미리 학습**할 수 있습니다.

입력한 기출 질문이 있는 경우 해당 질문을 우선 반영하고, 사용자가 입력한 자기소개서·실적·평가 기준 등을 기반으로 추가 예상 질문도 생성합니다.

#### 제공 기능

* 입력한 **기출 질문에 대한 모범 답안 생성**
* 참고자료 기반 **추가 예상 질문 생성**
* 각 문항별 출처 구분

  * `기출`
  * `AI 생성`
* 질문별 모범 답안 확인
* 문항별 음성 재생
* 전체 질문·답변 연속 음성 재생

예를 들어 다음과 같은 형태로 구성됩니다.

```text
[기출]
Q1. Director가 된다면 현재와 무엇이 달라져야 한다고 생각합니까?

모범 답안
...

[기출]
Q2. 본인이 다른 승진 후보자와 차별화되는 강점은 무엇입니까?

모범 답안
...

[AI 생성]
Q3. 향후 3년간 조직에 어떤 사업적 기여를 할 계획입니까?

모범 답안
...
```

### 예시 학습 흐름

```text
자기소개서 / 실적 / 평가기준 입력
              │
              ├── 기출 질문 입력(선택)
              │
              ▼
        AI 참고자료 분석
              │
              ▼
 ┌────────────────────────┐
 │     예상 질문 구성      │
 │                        │
 │  • 기출 질문           │
 │  • AI 추가 예상 질문   │
 └───────────┬────────────┘
             │
             ▼
       모범 답안 생성
             │
             ▼
      텍스트 / 음성 학습
             │
             ▼
       실제 모의 면접
```

> [!TIP]
> 모범 답안을 문장 전체로 암기하기보다는 **답변 구조 → 핵심 메시지 → 주요 사례** 순서로 익힌 뒤 자신의 표현으로 답변하는 방식으로 활용하는 것을 권장합니다.

### 03. 모의 면접

입력한 자료를 기반으로 AI 면접관과 실제 승진 인터뷰와 유사한 형태로 대화를 진행합니다.

#### 지원 기능

* **텍스트 채팅**
* **브라우저 음성 인식**
* **AI 질문 음성 출력(TTS)**
* 입력 자료를 반영한 맞춤형 질문
* 기출 질문을 고려한 인터뷰 진행
* 사용자 답변을 기반으로 한 후속 질문
* 선택한 면접 스타일에 따른 질문 강도 조정
* 1인 / 3인 패널 면접 방식 지원

### 면접 스타일

| 유형      | 설명                                |
| ------- | --------------------------------- |
| **압박형** | 답변의 논리, 수치, 근거 및 실행 가능성을 집중적으로 검증 |
| **균형형** | 성과·리더십·사업기여·조직기여 등을 균형 있게 질문      |
| **코칭형** | 답변을 유도하고 강점 및 개선 가능성을 확인하는 방식     |

### 패널 구성

| 구성        | 특징                      |
| --------- | ----------------------- |
| **1인 패널** | 한 명의 면접관과 집중적인 질의응답     |
| **3인 패널** | 서로 다른 관점의 면접관이 순차적으로 질문 |

---

### 04. 인터뷰 피드백

모의 면접 종료 후 전체 질문과 답변을 분석해 구조화된 피드백을 제공합니다.

#### 주요 평가 항목

* **잘한 점**
* **보완할 점**
* **종합 평가**
* **실전 인터뷰 Tip**

또한 실제 면접에서 중요도가 높았던 질문 중 **3개를 선정**하여 사용자가 입력한 참고자료를 반영한 **모범 답안 예시**를 제공합니다.

```text
모의 면접 종료
        │
        ▼
전체 질문 / 답변 분석
        │
        ├── 잘한 점
        ├── 보완할 점
        ├── 종합 평가
        └── 실전 Tip
        │
        ▼
중요 질문 3개 선정
        │
        ▼
참고자료 기반 모범 답안 생성
```

전체 면접 기록은 복사하여 별도로 저장하거나 이후 답변 개선에 활용할 수 있습니다.

# 실행 방법

별도의 설치 과정 없이 `index.html` 파일을 브라우저에서 열면 사용할 수 있습니다.

```text
index.html
```

보다 안정적으로 실행하려면 로컬 웹서버를 사용할 수 있습니다.

## Python을 이용한 실행

```bash
# 현재 디렉터리에서 간단한 로컬 웹서버 실행
python3 -m http.server 8000
```

이후 브라우저에서 다음 주소로 접속합니다.

```text
http://localhost:8000
```

# AI 모델

이 앱은 **Anthropic API**를 통해 Claude 모델을 호출합니다.

기본 모델은 **Claude Haiku 4.5**입니다.

```javascript
const ANTHROPIC_MODEL = "claude-haiku-4-5-20251001";
```

현재 구현에서는 모의 면접에서 필요한 다음 요소를 고려해 Claude Haiku 4.5를 기본 모델로 사용합니다.

* 한국어 질의·응답
* 빠른 응답 속도
* 반복적인 인터뷰 진행
* 문맥을 고려한 후속 질문
* 구조화된 피드백
* API 사용 비용

---

## 고급 모델 사용

보다 정교한 질문과 피드백이 필요한 경우 **Claude Sonnet 5**로 변경할 수 있습니다.

`callModelOnce` 함수의 `ANTHROPIC_MODEL` 값을 변경합니다.

### 기본 모델

```javascript
const ANTHROPIC_MODEL = "claude-haiku-4-5-20251001";
```

### 고급 모델

```javascript
const ANTHROPIC_MODEL = "claude-sonnet-5";
```

| 모델                   | 권장 용도         | 특징                  |
| -------------------- | ------------- | ------------------- |
| **Claude Haiku 4.5** | 반복적인 일반 모의 면접 | 빠른 응답 및 상대적으로 낮은 비용 |
| **Claude Sonnet 5**  | 최종 실전 대비      | 보다 정교한 질문 및 피드백     |

> [!NOTE]
> Claude 모델 및 Model ID는 향후 변경 또는 지원 종료될 수 있습니다.
> 장기간 프로젝트를 운영할 경우 Anthropic 공식 Model 목록을 정기적으로 확인하는 것을 권장합니다.

# Anthropic API Key

> [!IMPORTANT]
> 이 앱의 AI 기능을 사용하려면 **Anthropic API Key가 필요합니다.**

화면의 다음 위치에서 API Key를 입력합니다.

```text
01 자료 준비
    └─ F. Anthropic API Key
```

API Key는 Anthropic Console에서 생성할 수 있습니다.

[Anthropic Console - API Keys](https://console.anthropic.com/settings/keys)

Claude API는 Claude.ai의 Free / Pro / Max 구독과 별도로 운영됩니다.

API 사용을 위해 Anthropic Console에서 **Usage Credit을 충전**하고, 실제 API 사용량에 따라 Credit이 차감됩니다.

> [!NOTE]
> 실제 API 비용은 다음 요인에 따라 달라집니다.
>
> * 사용하는 Claude 모델
> * 자기소개서 등 입력 자료의 길이
> * 기출 질문 개수
> * 모의 면접 진행 횟수
> * 질문 및 답변 길이
> * 예시 학습 및 피드백 생성 횟수

개인 연습 시에는 Anthropic Console의 **Usage / Cost** 메뉴에서 사용량을 주기적으로 확인하는 것을 권장합니다.

# API Key 저장

`이 브라우저에 저장` 옵션을 활성화하면 API Key를 브라우저의 `localStorage`에 저장할 수 있습니다.

```javascript
localStorage
```

이를 통해 다음 접속 시 API Key를 다시 입력하지 않고 사용할 수 있습니다.

> [!WARNING]
> **공용 PC에서는 API Key 저장 기능을 사용하지 마세요.**

특히 다음 환경에서는 저장하지 않는 것을 권장합니다.

* PC방
* 공용 PC
* 공유 업무용 PC
* 여러 사용자가 동일한 Browser Profile을 사용하는 환경

# GitHub 업로드 시 주의

> [!CAUTION]
> **Anthropic API Key를 GitHub Repository에 절대로 포함하지 마세요.**

다음과 같이 API Key를 HTML 또는 JavaScript 코드에 직접 입력해서는 안 됩니다.

```javascript
// 잘못된 예
const API_KEY = "sk-ant-api03-xxxxxxxxxxxxxxxx";
```

GitHub에 Commit 또는 Push하기 전 다음 항목을 확인하세요.

* [ ] `index.html`에 API Key가 포함되어 있지 않은지 확인
* [ ] JavaScript 코드에 API Key가 Hard Coding되어 있지 않은지 확인
* [ ] 테스트용 API Key가 남아 있지 않은지 확인
* [ ] `.env` 등 환경설정 파일이 Commit되지 않았는지 확인
* [ ] Git Commit History에 API Key가 포함되지 않았는지 확인

> [!IMPORTANT]
> API Key가 GitHub에 노출된 경우 코드에서 삭제하는 것만으로는 충분하지 않습니다.
>
> **노출된 API Key를 즉시 폐기(Revoke)하고 새로운 Key를 생성하세요.**

# 데이터 및 개인정보 보호

Anthropic API와 같은 상업용 서비스에서는 기본적으로 API 입력 및 출력을 모델 학습에 사용하지 않는 정책을 적용하고 있습니다.

다만 승진 심사 자료에는 다음과 같은 회사 내부정보 또는 민감한 정보가 포함될 수 있습니다.

* 자기소개서
* 인사평가
* 고객사 정보
* 프로젝트 정보
* 계약금액
* 매출 실적
* 내부 조직 정보
* 사업 전략
* 미공개 프로젝트
* 실제 승진 심사 기출 질문

따라서 필요한 범위만 입력하고 민감한 내용은 가능한 한 **비식별화**하여 사용하는 것을 권장합니다.

### 비식별화 예시

```text
KB○○카드
→ 국내 대형 카드사

○○전자
→ 국내 대형 제조기업

12억 원 규모 계약
→ 대규모 보안 컨설팅 계약

홍길동 부장
→ 고객사 담당자
```

### 입력을 권장하지 않는 정보

* ID / Password
* API Key / Access Token
* 주민등록번호
* 계좌 및 카드정보
* 고객 개인정보 원문
* 시스템 관리자 계정
* 중요 시스템의 인증정보
* 회사 또는 고객사의 비밀정보

> [!WARNING]
> 회사 내부자료나 고객정보를 외부 AI API에 입력할 수 있는지는 해당 회사의 **정보보호 정책, 생성형 AI 사용 정책 및 고객 계약 조건**을 우선 확인하세요.

# 브라우저 직접 API 호출 구조

현재 앱은 별도의 Backend 없이 사용자의 브라우저에서 Anthropic API를 직접 호출하는 형태입니다.

```text
┌─────────────────────────────┐
│       사용자 Browser         │
│                             │
│  • index.html               │
│  • JavaScript               │
│  • 사용자가 입력한 API Key   │
└──────────────┬──────────────┘
               │
               │ HTTPS
               ▼
┌─────────────────────────────┐
│       Anthropic API         │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│          Claude             │
└─────────────────────────────┘
```

이 방식은 별도의 서버 구축이 필요하지 않아 **개인이 직접 사용하는 연습용 도구**에는 간단하고 편리합니다.

다만 API Key가 브라우저 환경에 존재하기 때문에 **불특정 다수에게 제공하는 공개 서비스 구조에는 권장하지 않습니다.**

# 여러 사람이 사용하는 경우

조직 내부 또는 여러 사용자가 사용하는 형태로 제공하려면 **Backend 또는 Serverless Proxy**를 구성하는 것을 권장합니다.

## 권장 아키텍처

```text
┌─────────────────────────────┐
│       사용자 Browser         │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│   GitHub Pages / Web App    │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│  Backend / Serverless Proxy │
│                             │
│  • Anthropic API Key 보호   │
│  • 사용자 인증              │
│  • Rate Limiting            │
│  • 입력값 검증              │
│  • 사용량 / 비용 통제       │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│       Anthropic API         │
└──────────────┬──────────────┘
               │
               ▼
            Claude
```

구현 가능한 환경의 예시는 다음과 같습니다.

* Cloudflare Workers
* AWS Lambda
* AWS API Gateway
* Azure Functions
* Google Cloud Functions
* Vercel Functions
* Netlify Functions

fetch(...)
```

주요 변경 대상은 다음과 같습니다.

API Endpoint
API 인증 방식
Request Header

```

## 음성 인식

마이크 입력은 **Web Speech API**를 사용합니다.

| 브라우저           | 권장 수준        |
| -------------- | ------------ |
| Google Chrome  | 매우 권장        |
| Microsoft Edge | 매우 권장        |
| Safari         | 일부 기능 차이 가능  |
| Firefox        | 지원 환경에 따라 제한 |

음성 인식 기능은 Chrome / Edge 계열에서 사용하는 것을 권장합니다.

Web Speech API를 지원하지 않는 브라우저에서는 자동으로 **텍스트 입력 방식만 활성화**됩니다.

## 음성 합성 (TTS)

면접관 질문과 예시 답안을 음성으로 들려주는 기능은 브라우저의 음성 합성 기능을 사용합니다.

```javascript
window.speechSynthesis
```

TTS는 다음 용도로 활용됩니다.

* AI 면접관 질문 읽기
* 예시 학습 질문 읽기
* 모범 답안 읽기
* 문항별 음성 재생
* 전체 질문·답변 연속 재생

운영체제 또는 브라우저에 한국어 음성이 설치되어 있지 않은 경우 기본 음성으로 대체될 수 있습니다.
