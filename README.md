# 승진 심사 모의 면접 (Promotion Interview Simulator)

회계법인 파트너 패널 승진 인터뷰를 텍스트 또는 음성으로 연습할 수 있는 싱글 HTML 웹앱입니다.
프레임워크 의존성 없이 순수 HTML/CSS/JS로 작성되어 있어 정적 파일 그대로 브라우저에서 열거나
GitHub Pages 등 어떤 정적 호스팅에도 바로 배포할 수 있습니다.

## 주요 기능
- **자료 준비**: 승진 대상 직급, 면접 스타일(압박형/균형형/코칭형), 패널 구성(1인/3인),
  자기소개서·실적·평가 기준 등 참고 자료 입력 (텍스트 붙여넣기 또는 `.txt`/`.md` 파일 업로드)
- **모의 면접**: 텍스트 채팅 또는 브라우저 음성 인식(Web Speech API)으로 실시간 대화 진행,
  AI 질문을 음성(TTS)으로 듣기 지원
- **피드백**: 면접 종료 후 잘한 점 / 보완할 점 / 종합 평가 / 실전 팁을 구조화된 형태로 제공하고,
  면접에서 나온 중요 질문 3~4개에는 참고 자료를 반영한 **모범 답안 예시**도 함께 제공합니다.
  전체 기록 복사 가능

## 실행 방법
`index.html` 파일을 브라우저에서 열면 바로 사용할 수 있습니다.

```bash
# 로컬에서 간단히 띄우고 싶다면
python3 -m http.server 8000
# 이후 브라우저에서 http://localhost:8000 접속
```

## 중요: API 연결에 대해
이 앱은 **Anthropic API**를 통해 **Claude Haiku 4.5**를 호출합니다. 무료 오픈소스 모델(Gemma, Solar,
Nemotron 등) 대신 Claude로 바꾼 이유는 안정성과 한국어 품질 때문입니다 — 무료 모델은 서버가 혼잡할 때
언어가 뒤섞이거나 알아볼 수 없는 텍스트가 나오는 경우가 있었는데, Claude는 상용급으로 안정적으로
서비스되어 이런 문제가 거의 없습니다. 별도 서버나 백엔드 없이, 브라우저에서 Anthropic API를 직접
호출하는 구조입니다.

**사용하려면 Anthropic API 키가 반드시 필요합니다.** (Claude.ai 미리보기 안에서든, GitHub Pages에
배포한 뒤든 예외 없이 필요합니다.) "01 자료 준비" 탭의 F번 항목에 키를 붙여넣으면 바로 동작합니다.

- 키는 https://console.anthropic.com/settings/keys 에서 발급받을 수 있습니다. 가입 시 신용카드 없이
  (전화번호 인증만) 약 **$5 무료 크레딧**이 주어집니다.
- 이 앱처럼 짧은 대화 위주의 세션은 비용이 매우 낮아(세션당 보통 몇 센트 이하), 무료 크레딧으로
  개인 연습용으로는 상당히 오래 쓰실 수 있습니다.
- 키는 이 브라우저에서 Anthropic API로만 직접 전송되며, 그 외 어디로도 전송되지 않습니다.
- Anthropic API(상업용 제품)는 기본적으로 사용자의 입력·출력을 모델 학습에 사용하지 않습니다.
- "이 브라우저에 저장"을 켜면 `localStorage`에 저장되어 다음에 다시 입력하지 않아도 되지만,
  **공용 PC에서는 사용을 권장하지 않습니다.**
- **이 파일을 다른 사람과 공유하거나 GitHub 같은 공개 저장소에 올릴 때는 키를 반드시 지우고 올려주세요.**
  파일 자체에는 키가 저장되지 않지만(브라우저 저장소에만 남음), 혹시 실수로 값을 채운 채 커밋하지 않도록 주의하세요.
- 더 안전하게 여러 사람이 함께 쓰는 형태로 배포하려면, 키를 서버 쪽에 두는 자체 백엔드/서버리스 프록시를
  추가하는 것을 권장합니다. 이 경우 `callModelOnce` 함수의 `fetch` 대상 URL과 헤더 부분만 그 프록시에 맞게
  교체하면 나머지 로직은 그대로 재사용할 수 있습니다.
- 더 정교한 질문·피드백을 원하면 `callModelOnce` 함수 안의 `ANTHROPIC_MODEL` 값을
  `claude-haiku-4-5-20251001` 대신 `claude-sonnet-5`로 바꾸면 됩니다(품질은 더 좋지만 비용도 더 높습니다).

## 브라우저 호환성
- 음성 인식(마이크 입력)은 Web Speech API를 사용하며 Chrome/Edge 계열에서 가장 안정적으로 동작합니다.
  지원하지 않는 브라우저에서는 자동으로 텍스트 입력만 활성화됩니다.
- 음성 합성(TTS)은 대부분의 최신 브라우저에서 동작하며, 설치된 한국어 음성이 없을 경우
  기본 음성으로 대체됩니다.
